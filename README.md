# Super Trunfo - Países (Nível Avançado)

Este projeto é um simulador de batalha de cartas do Super Trunfo, focado em dados geográficos e econômicos de países. O programa permite cadastrar cartas e realizar batalhas escolhendo dois atributos para comparação.

## 🚀 Como Executar o Programa

### Pré-requisitos
* Um compilador de C (GCC, Clang ou MinGW).
* Terminal ou Prompt de Comando.

### Compilação
No terminal, navegue até a pasta do projeto e digite:
```bash
gcc CartasSuperTrunfo.c -o CartasSuperTrunfo
